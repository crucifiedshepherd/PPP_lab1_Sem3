## Описание проекта

Программа реализует анимацию отрисовки кругов по спирали с использованием библиотеки Tkinter. Круги последовательно появляются от центра на определённом расстоянии и под определённым углом, имитируя рост растения.

## Функциональные возможности

### Основной функционал

* отрисовка кругов по спирали;
* последовательное появление кругов;
* расположение кругов на разных расстояниях от центра;
* расположение кругов под разными углами;
* использование математических функций для расчёта координат.

### Дополнительный функционал

* симуляция роста растения по спирали;
* изменение размера кругов по мере роста;
* изменение цвета кругов от зелёного к жёлтому, затем к розовому и красному;
* эксперимент с иррациональным углом.

## Демонстрация работы

При запуске программы круги последовательно появляются от центра и разрастаются по спирали.

Первые 7 кругов имеют зелёный цвет. Затем цвет постепенно меняется от жёлтого к розовому и красному. Размер кругов также увеличивается по мере продвижения по спирали.

## Требования к системе

* Python 3.9 или выше;
* Windows, macOS или Linux;
* Tkinter;

1. Запустить файл `main.py`.
